# Stock Portfolio Tracker 📈

A command-line stock portfolio tracker built in Python that fetches real-time market data using `yfinance` and displays portfolio performance in a clean, formatted table using `tabulate`.

---

## Features

* **Real-Time Market Data**: Automatically fetches live current stock prices using the Yahoo Finance API (`yfinance`).
* **Portfolio Management**: Easily add or remove stocks along with their share quantities and purchase prices.
* **Profit & Loss Tracking**: Calculates individual and total investment values, tracking net profit/loss dynamically.
* **Formatted Outputs**: Renders clean, tabular summaries of your portfolio performance straight in the terminal.

---
